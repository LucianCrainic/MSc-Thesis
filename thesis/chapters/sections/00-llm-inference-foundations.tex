\section{Transformer computation}
\label{sec:llm-inference-foundations}

A language model takes a sequence of \textbf{tokens}, integer identifiers
from a vocabulary, and produces scores for possible next tokens.  A
tokenizer converts text into these identifiers; a token can represent a
word, part of a word, or another text fragment.  Token counts and text
lengths are therefore different quantities.  The decoder-only
transformer is the computational architecture considered here, derived
from the transformer introduced by Vaswani et al.~\cite{vaswani2017attention}.

An embedding lookup selects a learned vector for each token.  Positional
information allows the model to distinguish order.  A stack of layers
then transforms these vectors, combining \textbf{causal self-attention},
which mixes information from the available history, with feed-forward
transformations applied to each position.  Normalization and residual
connections control the transformations and preserve a path for the
layer input.  Finally, an output projection produces \textbf{logits}, one
score per vocabulary entry; these scores define a next-token distribution.
\figref{fig:transformer-overview} identifies the main operations and
where learned parameters participate.  Read each panel from bottom to
top: the left panel shows the complete model, and the right panel shows
one representative layer with normalization before each sublayer.
The layer's two residual paths bypass normalization and computation and
rejoin at the addition nodes.  The KV cache is stored state used by
attention, rather than another stage in the activation path.

\begin{samepage}
For one attention head, with input activation matrix \(X\), learned
projection matrices produce queries, keys and values:
\begin{equation}
\label{eq:scaled-dot-product-attention}
 Q=XW_Q,\quad K=XW_K,\quad V=XW_V,\qquad
 A=\operatorname{softmax}\!\left(\frac{QK^{\mathsf T}}{\sqrt{d_h}}+C\right)V.
\end{equation}
\eqcaption{Scaled dot-product attention.  The head dimension is \(d_h\);
\(C\) masks unavailable positions with negative infinity before the
row-wise softmax.}
\end{samepage}

For \(S\) positions in this single-head notation, \(Q,K,V\) each have
\(S\) rows and \(d_h\) columns; \(QK^{\mathsf T}\) has shape \(S\times S\).
Multiple heads perform related computations and their outputs are
combined by a learned projection.  Feed-forward sublayers use further
learned matrices and nonlinear functions.  The \(W\) matrices are
\textbf{persistent parameters}; \(X,Q,K,V,A\) are \textbf{input-dependent
values}.  Some of these values are temporary, while keys and values
may be retained to reuse the history in later evaluations.  These
storage roles, rather than the details of training or sampling, are the
basis of the following sections.
