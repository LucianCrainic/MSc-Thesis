\begin{abstract}
\noindent
This review asks a bounded question: what can the supplied literature
already support about large-language-model inference on a Xeon Max CPU,
and which measurements on the CRESCO8 Max~9480 partition would add
defensible evidence?  Four works are examined according to their actual
contribution and transfer limits: a Xeon Max LLM study, an Aurora memory
characterisation, an Aurora HPL/HPL-MxP deployment report, and an
architectural position paper.  The HPL/HPL-MxP source adds
useful evidence about explicit placement: its global matrix remains in
DDR for capacity, while selected CPU-side panel data are staged into HBM.
It does not, however, measure CPU-only inference or isolate an HBM effect.

The review identifies one primary empirical gap: the corpus contains no
controlled, same-socket comparison of local HBM and local DDR5 for
quantized LLM inference with prefill and sustained decode reported
separately.  Capacity crossing, KV-cache placement, and topology are
ranked as follow-on questions.  A static audit of \lcpp{} at commit
\commitshort{} shows that whole-process placement can be imposed
externally, which is sufficient for the primary comparison, whereas
independent CPU-side placement of weights and KV state is not exposed as
a stable user control.  Runtime modification is therefore treated as a
conditional contribution, justified only by a measured limitation.
\end{abstract}
